# Bookme: AI-Driven Inventory Forecasting System

## Description

Bookme is an AI-driven inventory forecasting system prototype. It demonstrates a static frontend for managing inventory, viewing forecasts, generating reports, and receiving alerts. The goal is to help small retail businesses predict stock needs and reduce stockouts.

## Features

- Inventory dashboard and item listing
- Demand forecasts page
- Low-stock alerts and notifications
- User management UI
- Reports and audit pages

## Installation / Run locally

This is a static website. You can run it in two ways:

1) Open files directly

 - Open the project folder in your file manager and double-click `index.html`.

2) Run a local static server (recommended)

From the project root run (PowerShell):

```powershell
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

Or with npx/http-server:

```powershell
npx http-server -p 8000
```
